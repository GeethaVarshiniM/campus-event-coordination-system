A full-stack web application designed to manage college events efficiently, allowing students to register for events and administrators to manage events, view registrations, and export participant data.

🚀 𝐏𝐫𝐨𝐣𝐞𝐜𝐭 𝐎𝐯𝐞𝐫𝐯𝐢𝐞𝐰

The College Event Management System streamlines the process of creating, managing, and participating in college events.
It provides role-based access for Students and Admins, ensuring secure and organized event handling.

Register for events
View registration status (Registered / Not Registered)

🧑‍💼 𝐀𝐝𝐦𝐢𝐧

Log in with admin credentials
Create and manage events
View student registrations for each event
Download registered student details in CSV format
Send reminder emails to registered students
